# EventRegistry

**EventRegistry** — это веб-приложение для автоматизации процесса регистрации, хранения и обработки информации о происшествиях и лицах, связанных с ними.

Приложение разработано в рамках учебной дисциплины «Автоматизация процессов жизненного цикла программного обеспечения» студентами Московского политехнического университета Новоселовой Марии и Пешковой Ульяной (группа 241-326).

## Функциональные возможности

Приложение поддерживает три роли пользователей с разным уровнем доступа:
*   **Администратор (`admin`)** — управление учётными записями пользователей и назначение ролей.
*   **Оператор (`operator`)** — добавление, редактирование и удаление происшествий, лиц и связей между ними; внесение решений; просмотр статистики.
*   **Пользователь (`user`)** — просмотр сведений о происшествиях, лицах и статистики без права изменения данных.

**Основные функции:**
1.  Ведение учёта происшествий (регистрационный номер, дата, тип, фабула).
2.  Фиксация принятых решений (отказ, возбуждение дела с указанием номера, направление по территориальному признаку).
3.  Ведение учёта лиц (ФИО, адрес, количество судимостей) и их ролей в происшествиях.
4.  Формирование статистических отчётов:
    *   Количество происшествий за указанный период.
    *   Количество происшествий с участием конкретного лица.
5.  Просмотр карточки лица со списком связанных происшествий.
